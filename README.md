# ONE SHOTICUS

*one punch. one mistake. game over.*

**Play it now: https://sebsgooey.github.io/oneshoticus/**

A browser roguelike where you one-shot everything — and everything one-shots you. Every fight is positioning and timing, not attrition. Descend forever, die once.

- Endless floors with a new enemy type every floor through 11, elites after 12
- 8 bosses with unique patterns (one of them stole your gimmick)
- 5 rotating dungeon themes, follow-cam rooms up to 1280x860
- All pixel art generated from text matrices at boot — zero image files
- Full chiptune soundtrack + sfx synthesized live with Web Audio — zero audio files
- One HTML file, no build step ([Phaser 3](https://phaser.io) from CDN)

## Controls

| Input | Action |
|---|---|
| WASD / arrows | move |
| SPACE / J / X / click | punch |
| M | mute |

## Run locally

Open `index.html` in a browser. That's it.
